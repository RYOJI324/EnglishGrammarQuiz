# えいご これ・あれ クイズ

## 目的

小学4年生が、英語の `this` / `that` / `these` / `those`、`I` / `you` / `he` / `she` / `they`、`am` / `are` / `is`、疑問文、Yes / No の答え方、単数・複数、`a` / `an` / `my` / `your` を段階的に練習するためのWEBアプリです。

最初は選択問題で練習し、慣れてきたら声に出して答える音読チェックに進みます。音読チェックではキーボード入力を使わず、子供が声に出して答え、親が横で採点します。

## 起動方法

`index.html` をブラウザで開きます。

## 使い方

1. 画面上部のレベルボタンで挑戦したいステージを選びます。
2. どのレベルも、敵を倒すステージバトル形式です。
3. 選択問題では、答えのボタンを押します。
4. レベル4の音読では、子供が声に出して答え、親が「できた」「もう一回」で採点します。
5. 5問全問正解なら必殺技で敵を倒します。
6. 1問でも不正解があると「プスン……」と不発になり、もう一回チャレンジできます。
7. 通常のクイズ画面は「れんしゅう」ボタンから開けます。

## ボスバトル

レベル1〜6はすべて、顔写真つき二頭身キャラで遊べるステージバトルです。

1. 「主人公の顔」から画像を選びます。
2. トリミング画面で写真をドラッグし、スライダーで拡大縮小します。
3. 「この顔で決定」を押すと、丸く切り抜いた顔が主人公キャラに入ります。
4. 「ボスの顔」から画像を選ぶと、ボスにも丸い顔写真を入れられます。
5. 各ステージで5問連続で英語問題に答えます。
6. 正解すると必殺技ゲージが20%ずつたまり、勇者のオーラがだんだん強くなります。
7. 5問全問正解なら、ほうき・車・消しゴム・洗濯機・プリント・ランドセルなどの意外な必殺技がゆっくり発動して勝利します。
8. 1問でも不正解があると「プスン……」と不発になり、もう一回チャレンジできます。

顔写真はブラウザ内だけで表示します。サーバーには送信せず、このアプリでは保存もしていません。

ボスバトルには「自動で次へ」「演出短め」「音」の設定があります。音はチェックを入れたときだけ鳴ります。

敵は選んでいるレベルに合わせて変わります。レベル1は `am/is/are スライム`、レベル2は `ぎもん文コウモリ`、レベル3は `Yes/No ゴーレム`、レベル4は `音読ドラゴン`、レベル5は `a/an 複数形モンスター`、レベル6は `ごちゃまぜ大王` です。

ステージバトル画面では、主人公・敵・必殺技ゲージ・問題・選択肢・メッセージができるだけ1画面に収まるように、通常クイズよりコンパクトな専用レイアウトにしています。

回答すると、画面端に小さく `✅ 正解！` または `💡 惜しい！` のトーストが出ます。正解時は問題カードが緑に光り、勇者のオーラが正解数に応じて段階的に強くなります。不正解時はカードが軽く揺れ、正解ボタンは緑、不正解で押したボタンは赤になります。各問題の演出は控えめにし、派手なパーティクルや敵の大きな動きは最後の必殺技・プスン演出に集中させています。敵のHPバーは表示せず、必殺技ゲージだけを見て進みぐあいを確認します。

## レベル説明

- レベル1：be動詞スライム  
  `This ___ a pencil.` や `I ___ happy.` のような基本の選択問題です。

- レベル2：疑問文コウモリ  
  `___ this a pencil?` や `___ he happy?` のように、疑問文のはじめの `Am` / `Are` / `Is` を選びます。

- レベル3：Yes/No ゴーレム  
  `Yes, it is.`、`No, they aren’t.`、`Yes, I am.` のような答え方を選びます。

- レベル4：音読ドラゴン  
  画面の質問を声に出して答えます。親が横で採点します。

- レベル5：a/an 複数形モンスター  
  `This is a pen.`、`This is an apple.`、`These are pens.`、`This is my pen.` のように、1つ・2つ以上・`a` / `an` / `my` / `your` を選びます。

- レベル6：ごちゃまぜ大王  
  レベル1〜5の内容を混ぜて、最後のラスボスに挑戦します。

## まとめ

- `I` は `am` と仲よし。
- `you` は `are` と仲よし。
- `he` / `she` は `is` と仲よし。
- `they` は 2人以上・2つ以上なので `are`。
- `this` / `that` は 1つなので `is`。
- `these` / `those` は 2つ以上なので `are`。
- `this` / `that` の答えは `it`。
- `these` / `those` の答えは `they`。
- `they` はそのまま `they` で答えます。
- `Are you ...?` と聞かれたら、答える人は「私」なので `Yes, I am.` / `No, I’m not.` で答えます。
- 普通の文では `You are happy.` のように `you` と `are` を使います。
- 1つのものには `a` をつけます。
- `apple` / `egg` / `orange` のように母音ではじまる単語は `an` を使います。
- 2つ以上なら `a` / `an` はつけず、`pens` / `apples` のように `s` をつけます。
- `my` や `your` があるときも `a` / `an` はつけません。

## 自動レベルアップ

各レベルは5問です。5問中4問以上正解すると次のレベルへ進めます。3問以下の場合は同じレベルをもう一度練習します。

間違えた問題は、次回の練習で出やすくなります。

## 問題追加方法

`index.html` の中にある `questions` 配列に問題を追加します。

選択問題の例：

```js
{
  id: "new-question-id",
  level: 1,
  type: "choice",
  questionText: "空らんに入る言葉を選ぼう",
  sentenceHtml: "This ___ a pencil.",
  japaneseMeaning: "これは えんぴつです。",
  choices: ["am", "are", "is"],
  answer: "is",
  explanation: "this は「近くの1つ」。1つなので is を使います。"
}
```

音読問題の例：

```js
{
  id: "new-speaking-id",
  level: 4,
  type: "speaking",
  questionText: "こえに出して答えよう",
  sentenceHtml: "Are these apples?",
  japaneseMeaning: "これらは りんごですか。",
  modelAnswers: ["Yes, they are.", "No, they aren’t."],
  explanation: "these は2つ以上なので、答えでは they を使います。"
}
```

文中の選択肢は `am` / `are` / `is` のように小文字にします。文頭の選択肢は `Am` / `Are` / `Is` のように大文字にします。
